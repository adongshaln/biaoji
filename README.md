# 标记 1.1.0

Paper 26.3 插件，配套客户端默认按 **G** 沿准星标记，可在「选项 → 控制 → 按键绑定 → Adongcraft」中修改。命令 `/biaoji` 仍然可用。

取消 F、中键和潜行挥手触发；F 恢复切换副手，中键恢复原版选取物品，避免蓄力时意外标记。容器内 F 仍按 ClickSorted 设置整理物品。

视线在 160 格内碰到方块或实体时，问号标在命中位置；没有命中时标在前方 50 格。问号持续 4 秒，实体标记跟随目标；每名玩家的触发间隔为 0.4 秒。

独立按键通过 `biaoji:mark` 发送请求，由服务器自行确定目标，不接受客户端提交坐标。AuthMe 未登录玩家不能标记。G 键由 Adongcraft 1.6.0 配套客户端提供，旧客户端可继续使用命令。
